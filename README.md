## Featured Projects

### NeuReport: Financial Report Automation Prototype

Team-based industry collaboration prototype for a banking use case. The project explored how financial news collection, data structuring, LLM-based report generation, and fund recommendation workflows could support daily market reporting.

- Built around financial news collection, Mandarin report generation, and fund recommendation drafts
- Includes a Flask-based demo interface and sample generated outputs
- Documents a RAG-style fund matching concept with conservative project limitations

Repository: [ktHuangkt/SunnyBank](https://github.com/ktHuangkt/SunnyBank)

### Schedule LINE Bot: LLM-Powered Reminder Assistant

Personal AI automation prototype that lets users create and manage reminders through natural language messages in LINE.

- Parses Mandarin schedule requests with an LLM API
- Stores structured schedules in SQLite
- Sends reminder notifications through LINE Messaging API
- Designed as a lightweight Flask service for Render deployment

Repository: [ktHuangkt/schedule-linebot](https://github.com/ktHuangkt/schedule-linebot)
